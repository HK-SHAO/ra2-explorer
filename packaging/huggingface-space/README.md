# RA2 Explorer

在浏览器中查看《红色警戒 2》和《尤里的复仇》的单位、声音、帧动画与派生预览。

在线版本为只读资料库，只包含 RA2 Explorer 生成的索引、模型、预览和浏览器媒体，不包含游戏安装目录、可执行程序或原始 MIX 归档。需要解析自己的官方安装、导入或导出 `.ra2pack` 时，请使用项目发行页提供的本地网页应用。

源码、发行包与问题反馈：<https://github.com/Hansimov/ra2-explorer>
