# 派生资源包

`.ra2pack` 用于备份或迁移某个资料库已经生成的索引、语义关联和浏览器产物。它不是游戏安装包，也不会为了导出而批量重建全部素材。

## 包含与排除

允许内容：

- 已去除本机根路径的 SQLite 索引快照；
- 单位、声音、文本和事件关系；
- 已生成的图片预览、模型场景和浏览器媒体；
- 重建上述内容所需的派生元数据。

明确排除 MIX、SHP、VXL、HVA、INI、CSF、PAL、VPL、AUD 等原始成员及 `extracted` 副本。导入器拒绝目录穿越、符号链接、加密条目、未知文件类型、超出上限的条目数或解压体积。

如果导入后的包没有某个尚未生成的预览，应用会要求重新关联合法游戏目录；它不会假定资源包包含完整游戏。

## 在设置中使用

“设置”的“派生资源包”区域可以导入 `.ra2pack`、导出当前资料库、下载已导出的包。设置侧栏只用于定位，相关操作与显示、载入类型、游戏目录和更新选项仍位于同一张可滚动页面中。

## 可选命令行

```bat
ra2exp.exe sources
ra2exp.exe resource-pack export SOURCE_ID
ra2exp.exe resource-pack list
ra2exp.exe resource-pack import PATH_TO_PACK
```

默认输出目录是 `.runtime\RA2MD-Ext\packages`，也可以用 `--output PATH` 指定文件。该目录被 Git 和公共 Windows 构建排除。

## 适用边界

资源包大小取决于实际浏览和缓存过的内容，不是稳定下载体积。公共 generic Windows 包只包含程序；Pages 使用单独生成、只含单位与声音的静态快照，不直接读取 `.ra2pack`。

即使资源包排除了原始格式，其中的图片、声音或模型仍可能来自受权利约束的素材。公开托管前必须确认实际授权，不能只因文件已经转换就推定可以再分发。
