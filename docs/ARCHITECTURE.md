# RA2 Explorer v0.8 架构

## 运行模型

RA2 Explorer 是单机、只读源数据的本地 Web 应用：

```text
合法安装目录 / Mod 目录
          │ 只读扫描与按需读取
          ▼
格式层（MIX / SHP / VXL / HVA / TMP / MAP / CSF / INI / AUD / BAG / Video）
          │                         │
          ▼                         ▼
RA2MD-Ext 派生工作区 ←────── 按需解包 / PNG / WAV / MP4 / 场景 JSON
          │
SQLite 索引 ── 语义层（RULES / ART / CSF / 组件关联）── CLI
                    │
                 FastAPI
                    │ 回环地址
                    ▼
              React 浏览器界面
```

Python 服务是唯一的数据访问入口。CLI 和 HTTP API 都调用 `SourceLibrary`、`AssetReader` 与格式层，不维护第二套解析逻辑。前端生产构建由同一服务提供，因此运行时不需要 Node，也不加载外部 CDN。本地模式读取用户的官方安装并监听回环地址；Hugging Face 托管模式从派生资源包预置同一索引和产物，只开放查询接口并监听容器端口。

## 数据边界

- `.runtime\RA2MD` 是只读官方安装；扫描、预览、验证和后台服务都不会修改文件或运行其中的 EXE。
- `.runtime\RA2MD-Ext\index\ra2-explorer.db` 保存索引；解析元数据、PNG、WAV、MP4 和三维场景 JSON 位于 `RA2MD-Ext\artifacts\v1`。普通浏览直接只读来源文件或 MIX 区段，不再永久复制每个已读成员；只有显式运行 `ra2exp extract` 时才把原始成员保存到 `extracted`。缓存键包含来源、扫描版本、资产标识、转换参数和解析器版本。
- `.runtime\RA2MD-Ext\reference` 保存可重新下载的文件名数据库、声音转录表、从本地官方任务音频校对出的 `mission-audio-transcript.json` 和供应来源清单。旧 `.runtime\ra2-explorer.db` 会一次性迁移到 `RA2MD-Ext`，新写入不再落到旧位置。
- 扫描器显式排除 `RA2MD-Ext`，防止派生结果被重复识别为原始游戏资产。
- 索引记录松散相对路径，或 MIX 根文件与嵌套条目链；读取时校验 CRC/大小，解码后的隔离缓存可在同一扫描版本中复用。`ra2exp cache stats` 可审计各类缓存占用，`ra2exp cache prune` 默认只移除可从游戏安装重新读取的历史 `extracted` 副本，不影响索引、预览、模型、转码音频或视频。
- `.runtime`、真实游戏目录、参考仓库、虚拟环境和前端构建产物均不进入 Git。

## 格式支持矩阵

| 格式 | 当前能力 | 说明 |
| --- | --- | --- |
| MIX / MMX / YRO | 解析、递归索引、按需读取 | 基础、扩展和 Blowfish 加密索引；同时检测 RA2/TS 与经典哈希 |
| PAL | 解析、网格预览 | 768 字节、256 色、6 位色值扩展到 8 位 |
| SHP (TS/RA2) | 元数据、逐帧 PNG | 支持压缩 0–3、裁剪帧、透明索引 0、可选调色板 |
| VXL | 体素列解码、等距 PNG、交互式 WebGL 三维模型 | 只发送表面体素；后端使用 TS/RA2 法线表和 `voxels.vpl` 亮度层确定最终索引色，前端以无二次光照材质显示，并支持玩家换色、正交相机、鼠标旋转、滚轮缩放与平移 |
| HVA | 帧/部件/3×4 变换矩阵解析与组合时间轴 | VXL 组合预览按部件名应用 HVA 帧变换，并支持 8 向世界坐标旋转 |
| TMP / TEM / SNO / URB / UBN / LUN / DES | 地块元数据、逐地块 PNG | 使用 TS/RA2 52 字节块头、菱形像素、深度层和可选 extra 层；歧义扩展先按内容区别 TMP 与 SHP |
| CSF | 标签、反码 UTF-16LE、Extra Value、全文检索 | 使用真实的 ` FSC` / ` LBL` / ` RTS` / `WRTS` 标识 |
| INI / TXT | 编码探测、结构统计、全文预览与检索 | 支持 UTF-8/UTF-16、GB18030 和 Windows-1252 回退 |
| MAP / MPR | 文本、元数据、对象布局图 | 读取地图边界、环境、建筑、单位、步兵、航空器、地形对象和路径点；当前是结构示意图，不是完整等距地表复刻 |
| WAV | 元数据、浏览器内播放、原始导出 | PCM 直接播放；IMA ADPCM 按请求转为 PCM16 |
| AUD | 结构校验、Westwood/IMA ADPCM 解码、WAV 播放 | 支持压缩类型 1 与 99，容忍零售文件最后一块的声明差异 |
| AUDIO.IDX / BAG | IDX v2 展开、3,438 条虚拟语音、WAV 播放 | 通过偏移直接读取所需 BAG 片段，不缓存或载入整个 BAG；支持 PCM16 与 IMA ADPCM |
| PCX | 尺寸/色彩模式、PNG 预览 | 通过 Pillow 解码并限制最大预览像素数 |
| VQA / BIK | 索引、搜索、按需 MP4 播放、原始导出 | 调用系统 FFmpeg 转为 H.264/AAC；不执行游戏目录中的程序，转换结果持久化到 `RA2MD-Ext` |
| VPL | 解析、索引、搜索、原始导出 | 校验 16 字节头、内置 PAL 和 `section_count × 256` 亮度查找表；自动参与 VXL 的二维与三维渲染 |
| FNT | 索引、搜索、原始导出 | 可在素材设置中按需显示，尚未提供专用视图 |
| 未知条目 | CRC、大小、原始导出 | 文件名未知时显示稳定的 `crc_XXXXXXXX` 名称 |

## 单位语义目录

语义层按实际游戏覆盖顺序合并 `rules.ini` / `rulesmd.ini`、`art.ini` / `artmd.ini` 和 CSF。松散文件优先于 MIX，`expandmd##` / `expand##` 优先于基础归档，MD 配置叠加在原版配置之上。缓存键包含来源扫描时间、状态与资产数量，重新扫描后自动失效。

实体来自 `VehicleTypes`、`InfantryTypes`、`AircraftTypes` 和 `BuildingTypes`，以规则节的 `Image`（缺省为实体 ID）选择 Techno 的 ART 节和主体文件，再结合 `Voxel/NewTheater` 解析真实资产；不能继续把该 ART 节自身的 `Image` 当作主体重定向，否则官方 `BFRT`、`CAML` 会分别被错误替换成 `SREF`、`JOSH`。ART 动画节仍按各自格式使用其 `Image`。列表不再以 `renderable` 作为默认条件，因此类型表中的所有规则对象都可检索，主体缺失是状态而不是隐藏条件。`Owner`、`TechLevel`、`Cost`、`BuildLimit`、`Capturable`、`NeedsEngineer`、`Civilian` 等 RULES 字段组合出可建造、英雄、中立科技、平民/场景和任务用途分支。VXL 单位会关联主体、HVA、`TUR` 炮塔、`BARL` 炮管与 Cameo；SHP 单位会按剧场扩展选择主体。组合预览按部件名或合法序号匹配 HVA section，并复刻 Westwood/OpenRA 的变换顺序：HVA 平移先按部件比例和边界/尺寸修正，局部坐标加入最小边界后应用矩阵，最后统一进行比例和 Y 轴翻转。这样主体、旋翼和附属件位于同一个世界坐标系，不再分别居中或远离主体；同一接口可选择 HVA 帧、8 向朝向和阵营色。VXL 在首次解析时预计算并复用各 limb 的表面体素；解析后的 VXL/HVA/SHP/VPL 对象保留一个有界的进程内 LRU，避免时间轴连续预览反复解码或重复筛选同一批组件，来源重扫后自动失效。

单位的 `Primary`、`Secondary`、`ElitePrimary` 与 `EliteSecondary` 会继续解析到武器节，再关联 `Projectile` 和 `Warhead` 节。详情接口保留每条关系的槽位、父节点、解析状态和关键参数；检索也覆盖这些依赖名称和参数。值 `none` 是游戏规则中的空引用，不计为缺失依赖。

动画关系在接口中带有明确角色：步兵 ART `Sequence` 生成主体动作，武器 `Anim` 生成开火效果，弹头 `AnimList` 生成命中效果；建筑 `Buildup` 生成建造序列，`ActiveAnim*`、`ProductionAnim`、`SpecialAnim`、展开和舱门字段生成运行附属层。`BibShape` 是地基图层而不是动画。ART 的 `End`/`LoopEnd` 是包含末帧的闭区间；`Shadow=yes` 的 SHP 后半段是与前半段逐帧配对的阴影层，建造或运行时在同一源画布下先绘制半透明阴影、再绘制主体，不能串行播放。建筑主体 SHP 中仅含索引 1 的后半段同样作为配对阴影从主体时间轴排除。武器或弹头列表会在保留不同候选的同时去除重复引用；N/NE/E/SE/S/SW/W/NW 开火素材作为同一武器事件的方向样本返回。`DeathWeapon` 爆炸与 `DebrisTypes/DebrisAnims/MetallicDebris` 飞散残骸是不同事件；残骸使用独立预览，不伪装成固定贴在单位中心的摧毁层。

声音关系从 RULES/ART 的语音、移动、部署、武器报告和动画字段继续追踪到 SOUNDMD/EVA、AUDIO.IDX/BAG、WAV/AUD 与 CSF。语音和音效以这些引用证据分类，容器格式不参与语义判断，因此 BAG 中的战斗音效和松散 WAV 中的台词不会再被颠倒。`VOX:` 的 Extra Value 会作为实际音频别名解析；官方中文 CSF 与 CnCNet 社区英文转录表按音频 stem 合并，接口分别保留原文、中文和文本标签。EVAMD 的 `Allied`、`Russian`、`Yuri` 字段分别规范为盟军、苏军和尤里版本；不能把实际存在的 `Russian` 误写成 `Soviet` 而漏掉苏军播报。缺少 `Text`/`VOX` 的 `Unit_Eva_*` 与 `Unit_Sofia_*` 会按游戏事件映射回规则实体，再从 RULES 的英文名和 CSF 的本地化名补齐单位播报。EVAMD 只是事件路由容器：`mis_*` 与 `coop_*` 属于任务对白，不因出现在 EVAMD 就冒充 EVA 播报；没有可听内容的 `DUMMY.WAV` 不进入播报分类，缺少人声的系统提示归入提示音效。没有官方文本或已校对转录的任务对白仍保持“无逐字稿”，不会把事件名伪装成台词。资产关系接口还直接返回媒体目录中的转录文本，因此 `tauli02` 等存在 CSF/社区字幕但没有单位、SOUND 或 EVA 事件绑定的语音，也能在数据详情中显示中英文；`Taunts/tauCCNN.wav` 使用零售多人嘲讽目录和国家码归类，RA2 `PropagandaTruck` 的五条遗留广播依据 SOUND/RULES 关系归入场景播报。没有逐句转录的战役片段会从稳定文件名生成任务/段落说明。独立媒体目录按单位语音、EVA 播报、战役语音、多人嘲讽、场景播报、提示音效、战斗音效、单位音效、环境音效和界面/过场音频分组，并保留事件、单位、阵营和国家反向关系。零售 `SIDENC*.MIX` / `LOCAL.MIX` 的稳定 AUD 界面名称，以及被 SOUNDMD 覆盖但仍存在于 RA2 SOUND 的 `Explosion05/10` 样本，保留其来源语义而不再落入“未分类”。关系是从官方配置与零售归档证据计算出的可重建视图，不写回源文件。

配色表（PAL）是 RA2 索引色资源的 256 色查找表：SHP/VXL 像素或体素保存的是颜色索引，而不是现代模型的位图贴图。TMP 使用 `iso*.pal`，SHP/VXL 主体使用 `unit*.pal`；具体 TEM/SNO/URB/UBN/LUN/DES 变体优先从资产所在剧场归档判断。独立武器、命中、爆炸和残骸 AnimType 默认使用 `anim.pal`，`AltPalette=yes` 才切到单位调色板；建筑挂接的 `Buildup`、`ActiveAnim*`、`ProductionAnim` 与 `SpecialAnim` 继承建筑单位调色板。建筑 SHP 即使来自 `SNOW.MIX` 也使用 `unitsno.pal`，不能因其等距布局误用 `isosno.pal`。VXL 场景契约 v4 标记 `westwood_vpl` 或兼容 `lambert` 光照；后端依据 VXL 的 TS 36 项或 RA2 244 项法线表、HVA 旋转和 Westwood 漫反射/高光公式选择 VPL 亮度层，再经游戏 PAL 与玩家色生成最终颜色。WebGL 对 VPL 结果使用无额外光照材质，避免重复着色。查看器从实际变换后的体素边界重新计算三维包围盒，把八个角投影到当前相机平面后同时适配横向与纵向视野；容器尺寸变化和重置视角都会重新适配完整模型。

语义目录当前是扫描索引上的可重建内存视图，不复制游戏内容，也不写回 RULES/ART。诊断接口分别统计实体可预览率、CSF 本地化率、组件关联率、单位类型覆盖和未解析依赖，并返回有限样本用于排障。完整 Mod Profile 和更多动画语义仍是后续能力。

Web UI 使用统一树复用来源、搜索和详情交互，不再保留顶部工具栏。左栏顶部只显示 RA2 Explorer，底部固定显示设置，并可收起为保留可访问标签的图标栏；折叠状态局限在导航组件，只更新工作台 class 与宽度变量，不触发集合、详情或 WebGL 场景重建。载具、航空器、步兵和建筑是“单位”的子节点，并继续按可建造、英雄、中立科技、平民/场景和任务用途分层；动画不作为独立导航节点，只作为单位事件预览。语音与音效继续按游戏事件语义分层；设置中启用的地图、图像、地形和规则文本是同级节点，不存在平行的“资源 / 单位”模式。游戏文本通过 OpenCC 在响应边界转换，默认返回简体、可切回原始繁体；检索词同时展开简繁变体，不修改 CSF 原文。集合区依据节点显示有效排序；list 采用双列，grid 采用内容卡片，两者共享查询、筛选、选中和分页状态，单位类型由树节点决定，集合内只保留阵营筛选。单位的“游戏建造栏”排序复刻原版 cameo 比较顺序：先匹配玩家阵营，载具与航空器再区分海军和 `ConsideredAircraft`，随后比较 `TechLevel`、基础造价与名称；没有具体对局和房屋折扣时使用 RULES 基础造价。独立的“可建造优先”开关可叠加在任一主排序之前，并把常规可建造与限造英雄排在任务、场景和中立对象之前。单位卡片右上角只以紧凑文本显示所属阵营或国家；无归属时不生成标记，避免低对比度游戏图标干扰主体预览。声音集合可按游戏事件筛选，并可切换为按单位与同一声音的关系分组；共享声音直接以关联单位名作为分组标题，同名单位只用其规则计算出的阵营/国家归属消歧，中立重复名合并且不暴露内部 ID。音频卡不再保留占位大图标。默认工作台是上方集合、下方宽屏详情；设置可切为集合与窄屏详情左右排列，并保存默认单位预览角度。该角度使用面向用户的相对语义，SHP 映射到其 N/NE/E/SE/S/SW/W/NW 帧序列，VXL 映射到固定等距投影下的模型旋转；默认右前侧三分之四视角，因此不会因两类格式的底层零度相反而把其中一类翻到背面。VXL 鼠标旋转只更新当前详情角度及方向关联，不改变全局偏好，重置操作回到偏好角度且不重新请求模型。两种布局方向的分隔条都支持指针拖动和键盘调节，弹出的独立详情始终使用宽屏排版和自身滚动容器。浏览上下文、选择、布局尺寸与滚动位置保存在浏览器本地并在刷新后恢复。单位详情标题位于信息列上方，规则属性依据内容宽度在一至三列间跨列。不同格式分别进入三维、单位动作顺序/全帧网格、按非透明内容适配/缩放/平移/重置的图像、单击播放音频、视频、地图或文本视图。单位详情使用“声音 / 动画 / 数据” tabs；声音只有在关联到具体单位时才使用“关联 / 数据” tabs，纯 EVAMD/SOUND 事件不重复展示关联卡，而是把事件 ID 和适用阵营压缩成数据标签。声音的数据页将大小、时长、采样率、位深、声道与编码压缩为可换行标签，较短的原文/中文也使用单行文本标签，容器较窄或文本较长时才切回整行换行块。切换单位时保留上一份有效详情直到新请求完成，避免 loading 空态卸载 canvas。单位动画只播放能够与当前主体可靠对齐的“主体动作 / 模型姿态”，建筑额外播放“建造、运行”；武器闪光、弹体、战斗部命中、`DeathWeapon` 与随机残骸仍保留在战斗依赖数据中，但在具备攻击者—弹道—目标—摧毁的完整场景合成前不生成孤立动画标签。三维相机跨越八向区间时只更新方向样本与投影，不重新请求模型。控制条覆盖在预览内，不改变 canvas 尺寸；同一 VXL/HVA 模型换帧只替换几何并保留相机与初始 fit bounds，不同稳定模型键在同一 renderer 中重新取景。关联声音合并重复槽位并使用紧凑的播放/暂停与行尾下载操作；数据 tab 中的标签、规则属性和资源文件默认展开，没有原文或中文时不生成空占位行。来源的 `scanned_at` 变化会同时刷新索引视图并切换派生缓存版本。

`TechLevel=-1` 但具有 `ConstructionYard` 或 `UndeploysInto` 的建造场按玩家部署建筑处理，不因 `Capturable` 被误分为中立科技。集合中的单位 grid 卡片只保留缩略图和名称，并使用按非透明主体裁边的独立派生预览。详情中的静态 SHP 帧按可见内容居中，连续播放仍保持源画布坐标。静态 fit 限制最大放大并保留按容器计算的边距，手动倍率允许低于 100%；切换资源时预加载图像会先测量新 fit，再与显示源一起提交，避免旧图短暂套用空样式。声音分组 header 将主标题与 ID/附加信息放在同一行并独立省略。宽屏详情使用确定的 `minmax(0, 1fr)` Grid 行限制预览列；右侧长内容只增加详情滚动范围，不再把 WebGL mount 和 canvas 撑高或形成 ResizeObserver 尺寸反馈。

单位 grid 只为可见区域及邻近滚动范围请求缩略图，并按渲染成本限制并发；VXL 卡片以较高权重占用队列，详情模型加载期间暂停新的卡片任务，避免大量 Python 体素投影与模型响应争用。步兵缩略图按透明主体重新裁边后保留约 42% 的边距，把最长轴占比限制在约 54%，避免单个 SHP 人物放大到接近整张卡片。缩略图裁边规则改变时同时提升服务端派生键和浏览器 URL 版本，防止旧图继续命中缓存。三维场景直接写入实例矩阵与颜色缓冲，复用服务端按实际体素计算的包围盒；VPL 已提供最终颜色时使用无冗余法线和 UV 的紧凑立方体几何，并确保首次取景只触发一次重绘。生产构建将延迟加载的 Three.js 核心与渲染器拆成稳定的缓存 chunk，查看器业务代码保持为独立小 chunk，避免常规 UI 变更使整个三维引擎缓存失效。用户显式启用高性能预载后，当前单位分类的模型响应写入最多 260 项的浏览器持久缓存，当前及相邻模型再进入最多 12 项、18 万体素的解析后 LRU；关闭开关会同时清理两级浏览器缓存。模型 URL 包含来源扫描版本，因此重新扫描不会复用旧场景。

SHP 单位的静态主体优先使用 Sequence 中的 `Ready`、`Guard` 等待机序列；朝向参数按序列第三项的 facing step 映射到实际源帧，不再只在 URL 中变化而始终渲染第一张有效帧。多个 ART 事件若引用同一主体文件并且起始帧、帧数、朝向步长及播放参数完全相同，目录只生成一个可播放事件并保留其余别名，避免把官方的占位或复用映射展示成多段重复动画。

## MIX 名称与加密

RA2/TS 的文件名标识是对大写文件名执行带特殊尾部填充的 CRC32。早期 Westwood 游戏使用 rotate/add 算法；扫描器根据名称命中情况选择哈希类型，而不是假定所有 MIX 相同。

加密 MIX 先从 80 字节密钥源推导 Blowfish 密钥，再解密索引区。索引、条目范围、嵌套深度、条目数量和根归档大小均有上限与边界校验。损坏的单个归档会作为错误记录，灾难性扫描失败则保留上一版可用索引。

## 本地 API

主要契约：

- `GET /api/sources`、`POST /api/sources`、`DELETE /api/sources/{id}`：列出、导入或从索引移除源目录；删除接口不删除源文件；
- `GET /api/discovery`：只读发现 Steam App 2229850、EA App/Origin 和旧版注册表安装；
- `POST /api/sources/{id}/scan`：原子替换该来源的索引；
- `GET /api/assets`：按来源、名称/CRC 和一个或多个格式分页检索，并以名称或体积稳定排序；
- `GET /api/assets/{id}/content`：导出原始资产；
- `GET /api/assets/{id}/metadata`：按格式读取结构化元数据；
- `GET /api/assets/{id}/text`：预览/检索 CSF、INI、MAP 与 TXT；
- `GET /api/assets/{id}/shp`、`preview.png`：兼容 SHP 帧接口及统一图像预览；HVA 可按帧生成同名 VXL 组合缩略图；
- `GET /api/assets/{id}/media`：播放 WAV、AUD 或 AUDIO.BAG 虚拟语音；
- `GET /api/assets/{id}/video.mp4`：按需转换并播放 VQA/BIK；
- `GET /api/assets/{id}/associations`：读取声音、动画和单位的反向语义关系，并返回未绑定事件的直接音频转录；
- `GET /api/assets/{id}/model.json`：读取 VXL 或同名 VXL/HVA 的 v4 浏览器三维场景，可选择 HVA 帧并返回 VPL 光照后的颜色；
- `GET /api/entities`：按来源、名称、类型、阵营和可预览状态检索规则实体，并返回与查询一致的 facets；
- `GET /api/media`：按语音/音效、游戏事件、阵营、说明或文件名分页检索语义媒体，并返回事件 facets；
- `GET /api/entities/{source}/{entity}`：读取规则、ART 参数和实际组件来源，`language` 可选择 `zh-CN` 或 `zh-TW`；
- `GET /api/entities/{source}/{entity}/preview.png`：按 `frame`、`facing`、`player_color` 渲染 VXL 多部件或 SHP 单位预览；SHP 建筑可附带 effect 资产、主帧、配对阴影帧和调色板类型，在原始画布坐标中生成稳定组合帧；
- `GET /api/entities/{source}/{entity}/model.json`：读取组合 VXL/HVA 三维场景；
- `GET /api/semantic/{source}/diagnostics`：检查实体、CSF、组件与武器依赖覆盖；
- `GET /api/player-colors`：列出预览可用的稳定阵营色预设；
- `GET /api/palettes`、`GET /api/stats`：辅助浏览；
- `POST /api/reference-data/names/sync`：同步固定提交的名称数据库。

声音转录通过 `ra2exp sync-audio-text` 显式同步到派生工作区；服务启动时将社区 XLSX 与本地 `mission-audio-transcript.json` 补充表按音频文件名合并，补充表优先且可同时提供原文与中文。官方 EVAMD/任务地图提供播放事件关联但没有字幕，因此任务对白的校对结果单独留在 `RA2MD-Ext`，不改写游戏安装。浏览请求不会隐式联网。

本地模式的 OpenAPI 页面在 `/api/docs`。生产端口固定为 `46120`，可通过 `pythonw.exe` 无窗口运行并登记为当前用户登录自启；本地 CLI 拒绝监听非回环地址。应用不会默认调用系统 URL 打开器，避免错误的浏览器/RemoteApp 关联产生外部弹窗。只有显式设置 `RA2_EXPLORER_HOSTED=1` 的容器模式允许监听 `0.0.0.0`，同时关闭 OpenAPI、目录发现、来源增删/重扫、资源包导入/导出和参考数据同步等写操作。该模式由 Hugging Face 的 HTTPS 入口负责外部访问，不用于把本地可写服务直接暴露到公网。

## 本地 Web 应用发行边界

- 用户界面始终运行在本机已有的 Edge 或 Chrome 中；`RA2 Explorer.exe` 只负责启动监听 `127.0.0.1:46120` 的本地 Python 服务并打开浏览器，不嵌入 Electron、WebView 或额外 UI 运行时。浏览器沙箱不能直接扫描任意安装目录，因此格式解析与只读文件访问仍由随包附带的本地服务完成。
- 公共发行包使用 `ra2exp package` 构建为 `generic` 模式，只包含前端、解析器、Python 运行时和固定参考数据，不包含任何游戏资产。首次启动时在浏览器中选择本机合法安装目录。
- `ra2exp package --game-dir <path>` 构建 `linked` 模式：预先生成索引，但数据库仍只读关联当前电脑上的原目录，不复制数百 MiB 的 MIX；标记为不可分享，避免把本机绝对路径误当作便携包发布。
- 只有显式增加 `--include-game-data` 才生成 `portable` 模式。该模式复制支持的素材数据并将索引改写为相对便携根，同时排除 EXE、DLL、脚本和驱动；它是本地授权场景的可选产物，不进入主分支或默认 GitHub Release。
- PyInstaller 使用 one-folder，两个启动入口共享 `_internal`。OpenCC 仅包含简繁检索实际使用的配置与词典，Pillow 仅保留 PCX/PNG 及绘制所需模块；发行审计会拒绝构建机路径和意外游戏可执行文件。

## 资源与可靠性限制

- 根 MIX 最大 1 GiB、单归档最多 4096 个条目、嵌套最大 6 层；这些是首版的防御性限制，不是格式极限。
- 资产与语义媒体 API 单页最多返回 500 条，实体目录最多返回 1000 条；前端通过可见滚动容器增量分页，不再把单页结果误表现为完整结果。
- MIX 松散条目通过 seek/read 读取，嵌套归档通过 mmap 视图遍历；BAG 虚拟音频只读取指定偏移片段。普通读取不再写出与 MIX 内容重复的原始副本；模型场景首次生成后保存为紧凑 JSON，命中时直接返回原始缓存字节并允许本机浏览器短期复用，不再重复解析与序列化；模型实现或主体解析规则改变时必须提升派生缓存及前端 URL 版本。过长的派生缓存身份会压缩为带稳定摘要的短文件名，给原子写入临时后缀保留 Windows 路径空间。格式解码仍有单资产防御性上限，尚无持久任务队列。
- 视频首次播放需要 FFmpeg 转码，之后复用 `RA2MD-Ext` 中的 MP4；转换使用 `-nostdin`、无窗口子进程、超时和同键互斥，避免命令行挂起或重复工作。
- 音频播放转码后的 PCM 上限为 512 MiB；不支持的编码仍可原样导出。
- VXL 最多 512 个部件、400 万总体素，单部件预览最多 30 万体素；HVA 变换最多 100 万组。
- TMP 最多 16384 个槽，CSF 最多 10 万标签/20 万字符串，文本最多 16 MiB；限制用于抵抗损坏或恶意文件。
- 已在合成的基础/扩展/加密/嵌套 MIX、SHP 压缩和格式有效的 VXL/HVA/TMP/CSF/WAV 样本上验证。
- 用户提供的官方 RA2/YR 安装已完成全目录索引：16,820 个资产，其中 3,438 条来自 AUDIO.IDX/BAG 的实际语音。原有 11 类 188 个真实资产验证为 188/188；另对 23 个 AUD 全量通过，并对 BAG 语音抽样 100/100 通过。
- 当前官方安装可建立 559 个规则实体，其中 535 个已有可预览主体（95.7%）。剩余 24 个包括游戏规则中的 Dummy/占位对象以及官方归档未附带主体文件的对象；它们会保留在列表中以便诊断和持续完善解析。`JUMPJET` 和 `CLEG` 已在规则类型表中实测索引为可建造步兵。`APOC` 已实测解析为“天启坦克”，并正确组合 `MTNK` 主体、炮塔、炮管及其 HVA、Cameo、语音和武器事件。`SHAD` 已实测读取 2 帧、3 部件 HVA，并通过不同帧、朝向与阵营色的组合预览。
- 同一官方安装可建立 3,322 条去重语义音频记录：2,532 条语音和 790 条音效，当前没有无依据的未分类项。其中 80 条 `Taunts` 多人嘲讽与 5 条 `PropagandaTruck` 场景播报均有明确事件类型；原先剩余的 17 条已由 RA2 SOUND、`SIDENC*.MIX` / `LOCAL.MIX` 归档及稳定零售名称确认成 2 条爆炸和 15 条界面/过场音频。修正 `Russian` 字段及 EVAMD 事件语义后可确认 616 个真正的 EVA 播报，616 个均有可验证文本；334 个任务对白中 209 个已有文本，剩余 125 个是官方配置不带字幕、且尚未完成校对转录的尤里复仇任务/合作任务对白。`SPSYREAD.WAV` 是无台词的心灵揭示就绪提示音，`DUMMY.WAV` 只有约 0.06 秒且不进入播报分类。1,309 个单位语音中已有 1,209 个带文本，剩余项主要是动物、无线电、Dummy 或不含人声的效果。分类使用单位 Voice 字段、EVA、SOUND、CSF、转录、零售目录与稳定名称的联合证据，不以 BAG/WAV/AUD 文件载体推断用途。
- 真实游戏目录始终作为静态字节源处理；开发、验证与后台服务均不会调用其中的可执行文件。

## 参考实现与可重复数据

格式行为交叉核对了 OpenRA（开发快照 `2f09f50d5c2c3508c857f703e50af27af2d5625f`）、`iron-curtain-engine/cnc-formats` 和 `ra2web/ra2web-studio`。其中参考项目对 VXL 头部和 TMP 字段位置存在冲突，当前实现采用 OpenRA 已用于实际游戏内容的 802 字节 VXL 头与 TMP 读取顺序，而不是照搬较新的不一致描述。运行时名称库固定在 `cnc-formats` 提交 `77da596ed72a1201740e054855bf2ff60640bfa9`；英文音频转录来自 CnCNet 社区维护的 RA2/YR 音频数据库。两个同步命令都会在 `RA2MD-Ext` 记录来源、时间和条目数量，参考数据不写入游戏安装。
